## 固定计费还是动态计费，这一项最影响账单

雨云游戏云有两种计费模式，选错了可能多花一半钱，也可能开到一半被扣费扣到手抖。

固定计费就是传统月租，费用按购买规格固定收取，跑满也不额外加钱，适合长期在线的服。

动态计费是雨云自己搞的模式：基础月租定得很低，然后按「CPU 电量」日结。规则很清楚——CPU 使用率基准值是 20%，低于 20% 不算耗电，超过 20% 的部分才计费，系统还会按实例规格每天赠送一定基础电量。闲时省钱、忙时火力全开，这个描述不算夸张，但反过来说，你的服如果天天满负荷，动态计费的账单会追上甚至超过固定计费。

判断标准很简单：只是周末和朋友玩几个小时，选动态；准备长期挂着、玩家随时可能进来，选固定。官网购买页支持在两种模式之间切换，但切换前后的成本要自己算一遍。

2. **进入控制台 → 游戏云 → 购买游戏云**。选择服务器类型（雨云面板 / MCSM 面板 / VPS）、游戏类型、服务端类型和版本。
3. **选机型和配置**。1.17 以上的 Java 版优先高主频机型，配置建议 4核 8G 起步；1.16+ 纯净服或小 mod 服可以选 Platinum 8259CL 压成本。
4. **选计费模式**。长期在线选固定计费，偶尔玩选动态计费。
5. **购买或先试用**。云服务器和游戏云产品支持 1 元试用一天（每款限 1 次，较贵的机型试用价会高一点，例如部分面板机型是 2 元/天）。
6. **面板里一键开服**。打开面板，选择服务端并安装，首次启动前记得把 eula.txt 里的 `eula=false` 改成 `eula=true`，否则服务端不会真正跑起来。
7. **拿到地址进游戏**。面板服在端口映射里能看到分配给实例的地址和端口，把这段地址填进游戏的多人游戏列表即可。
8. **后续优化**。把视距从默认值降到 `view-distance=8`、`simulation-distance=6`，装个 spark 看 CPU 和区块加载情况，比盲目升配置划算。

如果不想花钱，积分商城还能用签到、绑定账号等任务攒的积分兑换免费游戏云。库存每晚 8 点刷新，兑换后有效期有限，需要继续用积分续期；库存紧张的时候抢不到是常态，把它当成体验通道而不是长期方案更合适。

## 几个常被问到的问题

### 开服之后卡顿，是配置不够吗？
先别急着升级。高版本服务端对单核性能的要求远高于对核心数，视距、区块加载、实体数量、插件效率都会明显影响 TPS。先把视距降下来、用 spark 定位是哪个插件在拖性能，再判断要不要换机型。面板服支持在线切机型，试错成本比重新买一台低。

### 面板服需要独立公网 IP 吗？
面板服走的是 NAT 端口映射，默认没有独立公网 IP，玩家通过映射出来的地址和端口连接，自己玩和朋友联机够用。确有需求可以加购独立 IP（独享防护），成本会明显上升。

### 价格是固定的吗？
不是。同一档配置在西数不同机型、地区、带宽、硬盘、IP 和计费方式下价格差别很大，官网购买页的起步价也只是「起」。唯一可靠的做法是在下单页把自己的选择走一遍。

### 退款和试用政策呢？
雨云支持 7 天内无理由退款，每个账号限 3 次；云服务器与游戏云产品可 1 元试用一天，每款限 1 次。这两条对第一次接触的服主其实挺关键——不确定能不能跑顺，先用试用价压测一晚再决定。
